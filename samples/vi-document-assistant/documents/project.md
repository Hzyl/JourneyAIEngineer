# Tài liệu giả lập: Bài tập cuối workshop

Bài tập cuối workshop là phân tích dữ liệu chi tiêu bằng Python, có ít nhất ba kiểm thử.
Nộp bài tập bằng file ZIP gồm source, README và kết quả kiểm thử; không cần dùng Git.
Báo cáo đánh giá cần ghi các câu hỏi chưa trả lời được và nguồn trích dẫn của câu trả lời.
