# Exercise artifacts

App tạo workspace thực hành trong .data/workspaces để chạy local. Thư mục này dùng cho lời giải đã được bạn review và muốn lưu vào GitHub.

Không copy database hoặc output runtime vào đây. Khi hoàn thành một exercise:

1. Chạy lại test từ đầu.
2. Xóa secret, dữ liệu cá nhân và file sinh tạm.
3. Copy source, test và một README ngắn vào thư mục phù hợp.
4. Ghi điều đã học vào journal/weekly/.
